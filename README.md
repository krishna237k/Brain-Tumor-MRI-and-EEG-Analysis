# 🧠 Brain Tumor Detection and MRI Image Segmentation using OpenCV

## 📌 Project Overview
This project focuses on processing brain MRI images using Python and OpenCV to highlight potential tumor-like regions through digital image processing and image segmentation techniques.

The system applies image enhancement, grayscale conversion, thresholding, noise reduction, and morphological operations to process MRI scans and visualize segmented regions.

## 🎯 Objectives
- Process and enhance brain MRI images.
- Apply image segmentation techniques using OpenCV.
- Highlight potential abnormal regions in MRI scans.
- Visualize the original image alongside the processed and segmented outputs.
- Demonstrate fundamental Digital Image and Video Processing (DIVP) concepts.

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## ⚙️ Key Features
- Brain MRI image preprocessing
- Image enhancement and noise reduction
- Threshold-based image segmentation
- Morphological image processing
- Contour detection and region visualization
- Step-by-step visualization of processing results

## 🚀 Applications
- Academic learning and DIVP demonstrations
- Medical image processing research
- Understanding image segmentation techniques

## ⚠️ Disclaimer
This project is intended for educational and research purposes only. The segmented regions are not clinically validated tumor detections. The system does not replace professional medical diagnosis.

## 👥 Project Context
Developed as part of a Digital Image and Video Processing (DIVP) academic project to demonstrate OpenCV-based brain MRI image segmentation.
